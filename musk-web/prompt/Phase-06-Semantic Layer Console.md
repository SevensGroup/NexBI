# Musk Web Phase 6 — Semantic Layer Console

Implement the /semantic Semantic Layer Console.
Tabs: Metrics, Dimensions, Entities, Data Sources, Query Builder.
Metrics: ROAS, CTR, CPC, CPM, CPA, CVR, Spend, Revenue.
Dimensions: Campaign, AdGroup, Creative, Country, Device, Channel, Date.
Create MetricExplorer, DimensionExplorer, SemanticQueryBuilder, SemanticQueryPreview, and QueryCompilerViewer.
The Query Builder selects metric, dimension, filter, and date range, generates a Semantic Query, then shows Query Compiler → Elasticsearch DSL → Result.
Business semantics must take priority over database fields.

When finished, run npm run build and confirm there are no obvious TypeScript errors, unhandled exceptions, or meaningless TODOs.
