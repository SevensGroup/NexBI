# Musk Web Phase 4 — Tool Execution Console

Implement the Tool Execution Console.
ToolCall: id, runId, toolName, description, arguments, status, duration, result, error, risk.
Create ToolExecutionCard, ToolArguments, ToolResult, JsonViewer, ToolStatusBadge, and ToolTimeline.
Show Tool, Arguments, Status, Duration, Result, and Error.
Support View Arguments, View Result, Copy JSON, and Retry.
Timeline: Decision → Tool Started → Tool Completed → Observation.
Failures must not crash the page.

When finished, run npm run build and confirm there are no obvious TypeScript errors, unhandled exceptions, or meaningless TODOs.
