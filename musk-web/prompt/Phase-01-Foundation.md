# Musk Web Phase 1 — Foundation

Build the Vue 3 enterprise Agent Console foundation.
Stack: Vue 3, TypeScript, Vite, Vue Router, Pinia, VueUse, Tailwind CSS, Element Plus, ECharts, Vue Flow, Axios.
Create src/assets, components/{common,agent,execution,decision,task,tool,memory,evidence,report}, layouts, pages, router, stores, services/{api,sse}, types, mocks, composables, and utils.
Pages: Dashboard, Agent Center, Agent Workspace, Runs, Tasks, Memory, Semantic, Approvals, Settings.
Workspace has three columns: Agents/Tasks, Execution Timeline, and Context, plus an Agent Input bar at the bottom.
This phase uses mocks only. Do not connect a real API or SSE. Finish with npm run dev and npm run build.

When finished, run npm run build and confirm there are no obvious TypeScript errors, unhandled exceptions, or meaningless TODOs.
